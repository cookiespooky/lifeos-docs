# Задачи

## Что делает

Все задачи — строками в одном файле `tasks/backlog.md`, по разделам с тегами, в формате плагина Obsidian Tasks.
Задача со ссылкой на человека сама появляется в его заметке, задачи на сегодня — на странице дня.

```
- [ ] отправить акт [[personalities/Ольга бухгалтер]] #учёт 📅 2026-12-01
```

| знак | что |
|---|---|
| `📅 дата` | срок — только настоящий: обещали, назначили |
| `⏳ дата` | день, когда делать — выбираете вы |
| `🛫 дата` | раньше не начать |
| `⏫` `🔼` `🔽` | приоритет |
| `#тег` | раздел бэклога |

Сделано — `- [x] … ✅ дата`, отменено — `- [-]`.

## Как пользоваться

| скажите агенту | что будет |
|---|---|
| «напомни отправить акт Ольге в пятницу» | строка со сроком; дату агент назовёт числом |
| «сделал акт» | задача закрыта с датой |
| «что у меня на сегодня?» | сегодняшние и просроченные, по разделам, просроченные первыми |

Прежде чем завести задачу, агент ищет похожую: нашлась — дополняет её, вторую не заводит.

С кодом Life OS — ещё и командами:

```bash
lifeos note task list --tag учёт          # открытые задачи раздела
lifeos note task add учёт "отправить акт" # новая строка в раздел
```

## Что нужно

Плагин Tasks в Obsidian — в базовом хранилище он уже стоит, остаётся разрешить сторонние плагины.
