## Что делает

Читает новое в ваших чатах и кладёт в сводку: личные переписки, рабочие группы целиком, остальные группы — одной
строкой. **Только чтение:** ничего не отправляет и не отмечает прочитанным. Фото и документы новых сообщений из
личных переписок и рабочих групп сохраняет в `inbox/files/`.

## Что нужно

- Свои `api_id` и `api_hash`: [my.telegram.org](https://my.telegram.org) → API development tools → создать
  приложение (название и платформа любые). Чужие ключи не подходят: по ним Telegram отличает одно приложение от
  другого, и ограничение на них ударит по всем, кто ими пользуется.

## Как подключить

1. Запишите ключи и номер в `~/.config/lifeos/telegram.env` и закройте файл от чужих глаз:

   ```
   API_ID=…
   API_HASH=…
   PHONE=+…
   ```

   ```bash
   chmod 600 ~/.config/lifeos/telegram.env
   ```

2. Войдите один раз и введите код из Telegram (и пароль двухфакторной защиты, если включена):

   ```bash
   lifeos tg login
   ```

3. Рабочие группы, которые нужно читать целиком, перечислите в `lifeos.yaml`:

   ```yaml
   work_chats: [Название группы, Другая группа]
   ```

**Проверка:** `lifeos tg --list` печатает диалоги с новым и строку «запросов N/60».

## Как пользоваться

| скажите агенту | что будет |
|---|---|
| «посмотри телеграм» | сводка Telegram, обновлённые заметки о людях и задачи, кто ждёт ответа |
| «забери документы из чата с …» | файлы из названного чата — в `inbox/files/` |

Без агента — командами из хранилища:

```bash
lifeos digest tg                              # сводка Telegram
lifeos tg --chat "Название" --back 40         # последние 40 сообщений одного чата
lifeos tg files --chat "Название" --back 40   # документы из них; --photos — и фото
lifeos tg seen                                # отметить показанное просмотренным
```

Сохранять файлы сами — выключить: `tg_auto_files: no` в `lifeos.yaml`; не трогать одну переписку —
`tg_files_skip: [Имя]`.

Аккаунт личный: запросов за прогон немного и с паузами, но запускайте сводку по делу, а не каждую минуту.

## Если не работает

| что видно | что делать |
|---|---|
| «Нет API_ID и API_HASH» | нет файла `~/.config/lifeos/telegram.env` или в нём опечатка |
| «Telegram притормозил аккаунт, ещё …» | сработало ограничение Telegram: ждите названный срок, не перезапускайте |

## Где данные

Сессия входа — `~/.config/lifeos/telegram.session`. В хранилище — только отметки, какие сообщения уже показаны
(номера, без текста), и файлы, которые вы забрали. Тексты сообщений на диск не пишутся.
