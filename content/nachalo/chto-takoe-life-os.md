Life OS — способ работать с ИИ-агентом над своим делом так, чтобы он помнил контекст и не тратил силы на рутину.
Всё лежит у вас: обычные файлы Markdown в папке, удобнее всего — в хранилище Obsidian.

## Три части

| часть | что это | цена |
|---|---|---|
| **Хранилище** | папки и правила, по которым агент понимает ваши записи с первого разговора: входящие, люди, задачи, проекты | бесплатно |
| **Код** | автоматизация повторяющегося, чтобы агент не тратил на неё токены: Telegram и почта одной сводкой, документы по шаблонам, сайт | бесплатно, открытый код |
| **Память и навигация** | метод идей и решений и устройство записей, по которому агент находит нужное за пару шагов | 10 000 ₽ — [подробнее](https://antonlozhkin.ru/obsidian-guide/lifeos-templates/) |

Поставить Life OS под процессы компании целиком — [внедрение](https://lifeos.antonlozhkin.ru/).

## Что понадобится

- macOS или Linux, Python 3.10 или новее. Windows не проверялся.
- Агент: Claude Code или Codex по подписке Claude или ChatGPT. Без них часть работы делает модель по ключу API —
  об этом на странице [[telegram|Telegram]].
- Для документов в PDF — Chrome, Chromium, Edge, Brave или Яндекс Браузер.
