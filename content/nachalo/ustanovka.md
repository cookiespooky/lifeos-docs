# Установка

## Что делает

Ставит код Life OS на ваш компьютер, создаёт в хранилище папки и настройки и подключает агенту инструкции.
Повторный запуск ничего не затирает.

## Как поставить

1. Скачайте код и запустите установку, указав папку хранилища (если её нет — создастся):

   ```bash
   git clone <адрес репозитория Life OS> lifeos && cd lifeos
   ./install.sh ~/Documents/work
   ```

2. Откройте хранилище в Claude Code или Codex и скажите: **«установи lifeos»**. Агент проведёт по шагам: Telegram,
   почта, проверка. Секреты — ключи, пароли, коды — вы вводите сами в терминале; агент их не спрашивает.

Начинаете с нуля — возьмите готовое базовое хранилище: папка `starter-vault/` в том же репозитории. Скопируйте её
туда, где будут жить заметки, откройте в Obsidian и прочитайте «Начните отсюда.md».

## Проверка

Из папки хранилища:

```bash
lifeos digest --only tasks
```

Печатается сводка задач без ошибок — всё стоит.

## Если не работает

| что видно | что делать |
|---|---|
| `command not found: lifeos` | папки `~/.local/bin` нет в `PATH`: допишите в `~/.zshrc` строку `export PATH="$HOME/.local/bin:$PATH"` и откройте терминал заново |
| «Хранилище не найдено» | команда запущена не из папки хранилища: перейдите в неё или задайте `LIFEOS_VAULT=/путь` |

## Где что лежит

| где | что |
|---|---|
| хранилище: `lifeos.yaml` | настройки: папки, рабочие чаты, почтовый ящик. Секретов здесь нет |
| хранилище: `personalities/`, `contacts/`, `tasks/`, `inbox/`, `templates/documents/` | ваши данные |
| хранилище: `.lifeos/state/` | отметки просмотренного — номера сообщений, без текста |
| `~/.config/lifeos/` | ключи Telegram, сессия, пароль почты, ключ модели |
