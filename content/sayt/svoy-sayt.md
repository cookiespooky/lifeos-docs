## Что делает

Агент заводит вам сайт — отдельной папкой рядом с хранилищем, со своим репозиторием: хранилище закрытое, сайт
публичный. Страницы — заметки Markdown, их можно править в Obsidian; публикация — на GitHub Pages.

## Шаблоны на выбор

| что | пример |
|---|---|
| личный блог: записи с датой и тегами, лента, RSS | [пример](https://antonlozhkin.ru/np-template-blog/) · [шаблон](https://github.com/cookiespooky/np-template-blog) |
| документация или база знаний: разделы, поиск, навигация | [пример](https://antonlozhkin.ru/np-template-docs/) · [шаблон](https://github.com/cookiespooky/np-template-docs) |
| сайт услуг: услуги, цены, работы, отзывы, контакты | [пример](https://antonlozhkin.ru/np-template-services/) · [шаблон](https://github.com/cookiespooky/np-template-services) |

Ни один не подходит — агент расспросит, что должно быть на сайте, и предложит свой на основе ближайшего.

## Как пользоваться

Скажите агенту: **«сделай сайт»**, **«нужен блог»**, **«добавь на сайт страницу с ценами»**. Агент:

1. покажет шаблоны или план своего сайта и начнёт после вашего «да»;
2. заведёт папку рядом с хранилищем — из вашего репозитория на GitHub (кнопка **Use this template** на странице
   шаблона) или из копии шаблона, если аккаунта пока нет;
3. заполнит название и контакты, уберёт демо;
4. соберёт и покажет сайт у вас на компьютере.

Страницы по вашим заметкам агент пишет только по просьбе и показывает текст до сохранения: ничего личного, приватного
и из переписки без вашего «да».

## Опубликовать

Публикует отправка изменений в репозиторий сайта на GitHub — только по вашему слову: «сохрани» и «опубликуй» — разные
просьбы. Вход в GitHub делаете вы сами; свой домен — в настройках Pages репозитория.
